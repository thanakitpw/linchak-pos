# Business Plan — "POS" (SaaS ออกบิล + ต้นทุน/กำไร สำหรับแม่ค้าออนไลน์ไทย)

> เอกสารแผนธุรกิจ v1 · สกุลเงิน THB · ตัวเลขการเงินเป็นการประมาณการพร้อมสมมติฐานที่ระบุชัด — ปรับได้
> ผลิตภัณฑ์: web app (PWA) responsive Mobile + Tablet · ออกบิล + PromptPay QR + บันทึกต้นทุน → สรุปกำไรรายเดือน

---

## 1. Executive Summary

**POS** คือแอปออกบิลบนเว็บ (มือถือ+แท็บเล็ต) สำหรับพ่อค้าแม่ค้าออนไลน์รายเล็กในไทย ที่ตอนนี้ยัง "จดบิลในสมุด / พิมพ์ใน LINE / ไม่มีระบบ" จุดต่างคือ **ง่ายสุด + Thai-first + เห็นกำไรรายเดือนในหน้าเดียว** ซึ่งคู่แข่งส่วนใหญ่ทำไม่ได้

- **โมเดล:** ทดลองฟรี 7 วัน → 149 ฿/เดือน (แผนเดียวก่อน) — ไม่มี free tier ถาวร
- **จุดแข็งเชิงต้นทุน:** solo build ด้วย Claude Code (ต้นทุนตั้งต้น ~5,000–12,000 ฿ เพราะมีบริษัทรองรับแล้ว ไม่ต้องจดใหม่), ไม่ต้องเชื่อม payment gateway สำหรับ PromptPay (margin ~90%), ขายผ่าน LINE ก่อน + สร้างช่องทางการตลาดใหม่
- **เป้า 24 เดือน (base case):** ~550 paid, MRR ~82,000 ฿/เดือน (ARR ~983,000 ฿)
- **Unit economics:** LTV/CAC ~11–22x, กำไรขั้นต้น ~90%

---

## 2. ปัญหา & ทางแก้

**ปัญหา:** แม่ค้าออนไลน์รายเล็กออกบิลไม่เป็นระบบ, ไม่รู้ต้นทุน, สิ้นเดือนไม่รู้กำไรจริง เครื่องมือที่มีอยู่ "แพง/ซับซ้อน" (ZORT, Page365 700–2,000฿/เดือน) หรือ "ฟรีแต่ไม่ไทย + ไม่มีกำไร" (Loyverse)

**ทางแก้:** แอปออกบิลที่ (1) ใช้ง่าย/เร็วบนมือถือ-แท็บเล็ต (2) แนบ PromptPay QR ในบิลส่งเข้า LINE ได้เลย (3) บันทึกต้นทุนการซื้อ → **สรุปกำไรรายเดือนอัตโนมัติ** ราคาถูก/มีฟรี

---

## 3. ตลาด (Market)

- ตลาด Social Commerce ไทยปี 2025 คาดโตแตะ ~5.2 พันล้านดอลลาร์ (โต ~18.6%/ปี) และปี 2021–2024 โตเฉลี่ย ~28.8%/ปี *(ResearchAndMarkets, 2025)*
- ปี 2023 มูลค่า Social Commerce ไทย ~200,000 ล้านบาท, คนไทยใช้ social media >50 ล้านคน *(สสว.)*
- Content creator ไทย ~9 ล้านคน — ช่องทางขาย/รีวิวที่ป้อนผู้ขายรายย่อยเข้าตลาดต่อเนื่อง *(Marketing Oops, 2025)*

**ประมาณการ funnel (คร่าวๆ ระบุว่าเป็นการประมาณ):**
- TAM: ผู้ขายออนไลน์/social seller ในไทย — หลักล้านราย
- SAM: รายเล็กที่อยากได้เครื่องมือออกบิล+กำไรแบบง่าย — หลักแสนราย
- SOM (เข้าถึงได้จริงใน 2–3 ปี ผ่านช่องทางตัวเอง): ~5,000–20,000 users, จ่ายจริง ~3–5%

> ตลาดโตเร็ว + ฐานผู้ขายรายเล็กใหญ่มาก + ยังไม่มีเครื่องมือ "ออกบิล+กำไร" ที่ทั้งง่ายและ Thai-first = ช่องว่างชัด

## 5. โมเดลรายได้ & ราคา

| แผน | ราคา | รายละเอียด |
|---|---|---|
| **ทดลองฟรี** | 0 (7 วัน) | ใช้ได้เต็มทุกฟีเจอร์ 7 วัน แล้วต้องสมัครต่อ |
| **แผนหลัก** | **149 ฿/เดือน** (แผนเดียวก่อน) | ไม่จำกัดบิล/สินค้า + รายงานเต็ม + **ต้นทุน/กำไรรายเดือน** + PromptPay QR |
| *(อนาคต)* รายปี / tier สูง | ~1,490 ฿/ปี / ~349 ฿/ด. | ส่วนลดรายปี + หลายสาขา/หลายผู้ใช้ (เฟสหลัง) |

รายได้เสริมในอนาคต: add-on (เชื่อมบัญชี/ขนส่ง), lead ต่อยอดบริการ Best Solutions Corp (เว็บ/SEO/ads)

> ⚠️ **ข้อคิดเรื่อง trial 7 วัน:** value หลักของแอปคือ "กำไรรายเดือน" ซึ่งต้องใช้เกือบ 1 เดือนถึงจะเห็นรอบเต็ม — 7 วันอาจสั้นไปที่จะทำให้แม่ค้ารู้สึกถึงคุณค่านี้ แนะนำ (ก) โชว์ value เร็วผ่านบิลสวย+PromptPay+สรุปยอดตั้งแต่วันแรก หรือ (ข) พิจารณายืด trial เป็น 14 วันถ้า conversion ต่ำกว่าคาด

## 6. Go-To-Market

1. **ช่องทางขายหลัก = LINE (เริ่มแบบ manual):** ลูกค้าทักมาทาง LINE OA → ปิดการขายเองในไลน์ → เก็บเงิน (โอน) → เปิดบัญชีให้ · ยังไม่ทำ funnel/จ่ายอัตโนมัติในเฟสแรก
2. **สร้างช่องทางการตลาดใหม่ทั้งหมด:** เพจ/โซเชียล/คอนเทนต์ของ POS เอง "แม่ค้าออนไลน์ออกบิล+ดูกำไรยังไง" (ไม่ดึงช่องทางเก่ามาใช้)
3. **Growth loop ต้นทุน 0:** ทุกบิลที่ส่งลูกค้าผ่าน LINE มีแบรนด์ POS ติดไป → ลูกค้าบางคนเป็นแม่ค้าเอง → ทักมาสมัคร (viral)
4. **SEO/content:** บทความ "ออกบิล/คิดกำไรร้านออนไลน์" ของ POS
5. **Distribution = PWA ก่อน:** เปิดใช้ผ่านเว็บ/ติดตั้งลงจอ ยังไม่ลง Play/App Store (ไว้เฟสหลัง)
6. **Free trial 7 วัน:** ให้ลองเต็มฟีเจอร์ → โชว์ value เร็ว (บิลสวย+PromptPay+สรุปยอด) → แปลงเป็นจ่าย 149

## 7. การเงิน (Financial Plan)

### 7.1 ต้นทุนตั้งต้น (one-time, เงินสด)

| รายการ | ฿ |
|---|---|

| โดเมน + แบรนด์/โลโก้ | 1,500 |

| สำรอง/เผื่อ | 5,000 |

> จุดเด่น: ต่ำมากเพราะ solo build ไม่จ้างทีม + ใช้ VPS/เครื่องมือที่มีอยู่แล้ว + มีบริษัทรองรับแล้ว

### 7.2 ต้นทุนดำเนินงานรายเดือน (OPEX)

**ช่วงต้น (M1–6) — ใช้ free tier / self-host บน VPS เดิม**

| รายการ | ฿/เดือน |
|---|---|

| Vercel (hobby) | 0 |
| โดเมน (เฉลี่ย) | ~40 |
| Email (Resend free tier) | 0 |
| การตลาด (organic เป็นหลัก) | 0–3,000 |
| **รวม** | **~500–3,500** |

**ช่วงสเกล (M12–24) — paid ~200–550 ราย**

| รายการ | ฿/เดือน |
|---|---|
| Supabase Pro (หรือ VPS แรงขึ้น) | 900–2,000 |
| Vercel Pro | 700 |
| Storage/bandwidth | 500–1,500 |
| Email | 350 |
| การตลาด | 5,000–15,000 |
| Support/misc | 2,000 |
| **รวม (ไม่รวมเงินเดือนเจ้าของ)** | **~10,000–20,000** |

> COGS ต่อ paid user ต่ำมาก (~10–15 ฿/เดือน) และ **ไม่มีค่าธรรมเนียม payment gateway** เพราะ PromptPay QR สร้างเองในเครื่อง → กำไรขั้นต้น ~90%

### 7.3 Unit Economics (Pro user)

| ตัวชี้วัด | ค่า | ที่มา/สมมติฐาน |
|---|---|---|
| ARPU | 149 ฿/เดือน | ราคาแผนหลัก |
| Gross margin | ~90% | COGS ~10–15 ฿/user, ไม่มี gateway fee |
| Churn | 6%/เดือน | สมมติ (micro seller เลิกขายได้ง่าย) |
| อายุเฉลี่ย | ~16.7 เดือน | 1/churn |
| **LTV** | **~2,240 ฿** | 149 × 0.9 × 16.7 |
| CAC | ~100–200 ฿ | ผ่าน own audience/organic |
| **LTV/CAC** | **~11–22x** | เกณฑ์ดี > 3x |

### 7.4 ประมาณการเติบโต & รายได้ (3 scenarios)

**สมมติฐาน base case:** ผู้เริ่มทดลอง (trial signups) เพิ่มขึ้นเรื่อยๆ จากช่องทางตัวเอง, **trial→paid ~15%** (trial แบบไม่ผูกบัตร), churn 6%/เดือน
> trial conversion (~15%) สูงกว่าโมเดล freemium (~4%) มาก → ได้ paid เร็วขึ้นด้วยจำนวน signup ที่น้อยกว่า

| จุดเวลา | Trial สะสม | Paid | MRR (149฿) | ARR |
|---|---|---|---|---|
| M6 | ~450 | ~60 | ~8,900 | — |
| M12 | ~1,650 | ~200 | ~29,800 | ~357,000 |
| M18 | ~3,300 | ~350 | ~52,000 | ~626,000 |
| M24 | ~5,200 | ~550 | ~82,000 | ~983,000 |

**เทียบ 3 scenario ที่ M24:**

| Scenario | trial→paid | Paid | MRR | ARR |
|---|---|---|---|---|
| Conservative | ~10% | ~280 | ~41,700 | ~500,000 |
| **Base** | ~15% | ~550 | ~82,000 | ~983,000 |
| Optimistic | ~25% | ~1,000 | ~149,000 | ~1,788,000 |

### 7.5 P&L snapshot (base, ไม่รวมเงินเดือนเจ้าของ)

| | Year 1 | Year 2 |
|---|---|---|
| รายได้ subscription | ~145,000 | ~650,000 |
| ต้นทุน infra + การตลาด | ~50,000 | ~220,000 |
| **กำไรก่อนเงินเดือนเจ้าของ** | **~95,000** | **~430,000** |

### 7.6 Break-even

- **คุ้ม infra:** ~15–20 paid users → ประมาณ **M3** (เพราะ fixed cost ต่ำมาก + trial แปลงเป็นจ่ายเร็ว)
- **คุ้มรวมการตลาด + เงินเดือนเจ้าของ ~20,000฿/เดือน:** ต้องมี paid ~150–180 users → base case ~**M10–12**
- ถ้าเจ้าของยังไม่ดึงเงินเดือน โปรดักต์ทำกำไร(ก่อนค่าแรง) ได้ตั้งแต่ช่วงต้น เพราะ opex ต่ำ

> โมเดล trial แปลงเร็วกว่า freemium มาก → **Year 1 รายได้ ~145k** (ดีกว่าเดิมเท่าตัว) และคุ้มทุนเร็วขึ้น แต่ต้องระวังว่า **7 วันอาจสั้นไปสำหรับ value "กำไรรายเดือน"** (ดูข้อ 5) — จับตา trial→paid จริงในช่วงแรก

## 10. สรุปเชิงกลยุทธ์

โปรเจคนี้ไม่ใช่ "SaaS ที่หวังรวยเร็ว" แต่เป็น **สินทรัพย์ต้นทุนต่ำ margin สูง** ที่:
1. ทำกำไร (ก่อนค่าแรง) ได้ไวเพราะ opex ต่ำ + ไม่มี gateway fee
2. มี growth loop ในตัว (บิลที่ส่งลูกค้า = โฆษณาฟรี)
3. ป้อน lead ให้บริการอื่นของ Best Solutions Corp (เว็บ/SEO/ads)
4. ต่อยอด AI/automation (ของถนัด) เป็น moat ในเฟสหลัง

**ตัวเลขทั้งหมดเป็นประมาณการพร้อมสมมติฐาน** — แนะนำทำเป็นไฟล์ Excel แยกเพื่อปรับ signups/conversion/churn/ราคา แล้วดูผลแบบ interactive ได้
