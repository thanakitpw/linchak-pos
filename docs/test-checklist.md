# รายการทดสอบก่อนใช้งานจริง

> ทำเครื่องหมายไปเรื่อยๆ · เจอบั๊กให้จดไว้ท้ายไฟล์ในหัวข้อ "ที่เจอ"
> อัปเดตล่าสุด: 2026-08-06

**เครื่องหมาย**
`🤖` = ทดสอบด้วยการยิง API/SQL ไปแล้ว ผ่านแล้ว — ดูผ่านๆ พอ
`👤` = **ต้องใช้คนเทส** เครื่องจริง สายตาจริง หรือแอปจริง — ที่นี่คือที่ที่ควรใช้เวลา

## 0. เตรียมก่อนเริ่ม

```bash
pnpm dev        # http://localhost:3000
```

- [ ] มีบัญชีเทสอย่างน้อย **2 ร้าน** (เพื่อทดสอบว่าข้อมูลไม่รั่วข้ามร้าน)
- [ ] เปิดทั้ง **มือถือจริง** และ **แท็บเล็ต/desktop** — layout ต่างกันที่ 768px
- [ ] เปิด DevTools ค้างไว้ที่แท็บ Console — **ถ้ามี error แดงตอนไหน จดไว้ทันที**
- [ ] เตรียมรูปไว้ 2–3 รูปสำหรับอัปโหลด (โลโก้, รูปสินค้า, สลิป)

> ตอนนี้ฐานข้อมูลว่างสะอาด เหลือร้าน "ร้านเทส" ร้านเดียว ไม่มีสินค้า/บิล/ต้นทุน

## 1. สมัคร · ล็อกอิน · สิทธิ์ (FR-0)

- [ ] 🤖 ยังไม่ล็อกอิน เปิด `/sell` → เด้งไป `/login` พร้อม `?next=/sell`
- [ ] 👤 สมัครร้านใหม่ → เข้าแอปได้ทันที ได้ร้านชื่อตามที่กรอก สิทธิ์ owner
- [ ] 👤 สมัครด้วยอีเมลเดิมซ้ำ → ขึ้น "อีเมลนี้ถูกใช้แล้ว" **ไม่ใช่ข้อความอังกฤษดิบ**
- [ ] 👤 ใส่รหัสผ่านสั้นกว่า 8 → ฟอร์มไม่ยอมส่ง
- [ ] 👤 กรอกอีเมลผิด/รหัสผิดตอนล็อกอิน → ขึ้น "อีเมลหรือรหัสผ่านไม่ถูกต้อง"
      **แล้วอีเมลที่พิมพ์ไว้ยังอยู่ในช่อง** ไม่ต้องพิมพ์ใหม่
- [ ] 👤 ล็อกอินแล้วเปิด `/login` ซ้ำ → เด้งเข้าแอปเลย
- [ ] 👤 ออกจากระบบ → กลับมาที่ `/login` และกด back ไม่ควรเข้าแอปได้
- [ ] 👤 หน้าลืมรหัสผ่าน → กรอกอีเมล **ที่ไม่มีในระบบ** → ต้องขึ้นข้อความเดียวกับอีเมลที่มีจริง
      (ถ้าตอบต่างกัน หน้านี้จะกลายเป็นเครื่องมือเช็คว่าใครสมัครไว้บ้าง)
- [ ] ⏳ **ตั้งรหัสผ่านใหม่จากลิงก์ในอีเมล** — ยังเทสไม่ได้จนกว่าจะต่อ SMTP
      (โควตาอีเมลของ Supabase คือ 2 ฉบับ/ชม. และส่งได้เฉพาะอีเมลในทีมโปรเจค)

## 2. ตั้งค่าร้าน (FR-1)

- [ ] 👤 แก้ชื่อร้าน/สาขา/เบอร์ → กดบันทึก → **รีเฟรชแล้วค่ายังอยู่**
- [ ] 👤 อัปโหลดโลโก้ → ขึ้นทันทีไม่ต้องกดบันทึกซ้ำ → ไปดูใบเสร็จ **โลโก้ต้องขึ้นบนหัวบิล**
- [ ] 👤 อัปโหลดไฟล์ใหญ่เกิน 2 MB → ขึ้น "ไฟล์ใหญ่เกินไป" ไม่ใช่ error ดิบ
- [ ] 👤 ใส่เลข PromptPay เป็น **เบอร์บ้าน** (เช่น 021234567) → ต้องไม่ผ่าน
- [ ] 👤 ใส่เบอร์มือถือถูกต้อง → **QR ตัวอย่างขึ้นสดขณะพิมพ์**
- [ ] 👤 ลบเลข PromptPay ให้ว่างแล้วบันทึก → ถอดออกได้ ใบเสร็จเปลี่ยนเป็น QR เปิดบิลแทน
- [ ] 👤 **เปิด VAT** → ช่องอัตราภาษีโผล่ขึ้นมา
- [ ] 👤 **ปิด VAT** → ช่องอัตราหายไปเลย (ไม่ใช่จางลง ไม่ใช่กดไม่ได้)
- [ ] 👤 เปลี่ยนภาษาเป็นอังกฤษ → **ทั้งแอปเปลี่ยนทันที** รวมแท็บล่างและใบเสร็จ
- [ ] 👤 เปลี่ยนกลับเป็นไทย → กลับมาปกติ ไม่มีข้อความอังกฤษตกค้าง

## 3. สินค้า · หมวดหมู่ (FR-2)

### หมวดหมู่
- [ ] 👤 เพิ่มหมวดหมู่ + เลือกสี → จุดสีบนการ์ดสินค้าตรงกับที่เลือก
- [ ] 🤖 ตั้งชื่อหมวดซ้ำกับที่มีอยู่ → ขึ้น "มีหมวดหมู่ชื่อนี้อยู่แล้ว"
- [ ] 👤 แก้ชื่อ/สีหมวดที่มีอยู่ → chip ในหน้าขายเปลี่ยนตาม
- [ ] 🤖 **ลบหมวดที่มีสินค้าอยู่** → สินค้าไม่หาย แค่กลายเป็นไม่มีหมวด

### สินค้า
- [ ] 👤 เพิ่มสินค้าครบทุกช่อง (รูป, หมวด, ชื่อ, รายละเอียด, ราคา)
- [ ] 👤 เพิ่มสินค้าโดยไม่ใส่รูป → ขึ้นไอคอนแทน ไม่พัง
- [ ] 👤 **ชื่อสินค้ายาวๆ ภาษาไทยไม่มีเว้นวรรค** (เช่น "ข้าวเหนียวมะม่วงน้ำดอกไม้ชุดใหญ่พิเศษ")
      → ตัด 2 บรรทัดสวย **ไม่ล้นการ์ด** ทั้งหน้าสินค้าและหน้าขาย
- [ ] 👤 ราคามีสตางค์ (เช่น 45.50) → แสดง ฿45.50 ทุกที่ ไม่ปัดทิ้ง
- [ ] 👤 แก้ราคาสินค้า → หน้าขายเห็นราคาใหม่ทันที
- [ ] 👤 **แก้ราคาแล้วเปิดบิลเก่า** → บิลเก่าต้องยังเป็นราคาเดิม (BR-4 snapshot)
- [ ] 👤 ค้นหาสินค้าภาษาไทย → เจอ · ค้นคำที่ไม่มี → ขึ้น "ไม่พบสินค้าที่ค้นหา"
- [ ] 👤 กรองตามหมวด → เหลือเฉพาะของหมวดนั้น · กด "ทั้งหมด" → กลับมาครบ
- [ ] 🤖 กด "เลิกขายสินค้านี้" → ต้องกดยืนยันอีกครั้ง → หายจากทั้งหน้าสินค้าและหน้าขาย
- [ ] 👤 **VAT เปิด** → ฟอร์มสินค้ามีช่อง "ราคานี้รวมภาษีแล้ว" · **VAT ปิด** → ไม่มีช่องนี้

## 4. ขาย (FR-3) — หน้าที่ใช้บ่อยที่สุด เทสหนักที่สุด

- [ ] 👤 แตะสินค้า → เข้าบิล · **แตะซ้ำ → จำนวนเพิ่ม ไม่ใช่บรรทัดใหม่**
- [ ] 👤 กด +/− ปรับจำนวน → ยอดรวมเปลี่ยนทันที
- [ ] 👤 **ลดจำนวนถึง 0 → บรรทัดหายไป** ไม่เหลือบรรทัดจำนวน 0
- [ ] 👤 ใส่ส่วนลด → ยอดสุทธิลดตาม · ใส่ส่วนลดมากกว่ายอดรวม → ต้องไม่ติดลบ
- [ ] 👤 **บิลว่าง กดชำระเงินไม่ได้**
- [ ] 👤 เลือกเงินสด → ช่องรับเงินโผล่ → ใส่ 500 กับยอด 380 → **ทอน 120**
- [ ] 👤 ใส่เงินรับน้อยกว่ายอด → ไม่โชว์เงินทอน (หรือโชว์ว่ายังไม่พอ)
- [ ] 👤 เลือก PromptPay / โอนเงิน → ช่องรับเงินหายไป
- [ ] 👤 **instant add**: กด "เพิ่มสินค้าเร็ว" กรอกชื่อ+ราคา → เข้าบิลได้เลย
      แล้วสินค้านั้นไปโผล่ในหน้าสินค้าด้วย
- [ ] 👤 **🔥 กด F5 กลางบิล → บิลต้องยังอยู่ครบ** (เก็บใน sessionStorage)
- [ ] 👤 ปิดแท็บแล้วเปิดใหม่ → บิลหาย (ถูกต้อง — บิลค้างไม่ควรข้ามแท็บ)
- [ ] 👤 กด "ล้างบิล" → บิลว่าง และรีเฟรชแล้วยังว่าง
- [ ] 👤 **มือถือ (< 768px)**: มีแถบสรุปล่าง → กดแล้วบิลเปิดเป็น sheet เลื่อนขึ้นมา
- [ ] 👤 **แท็บเล็ต (≥ 768px)**: บิลอยู่คอลัมน์ขวาถาวร ไม่มีแถบล่าง
- [ ] 👤 หมุนแท็บเล็ตแนวตั้ง/แนวนอน → layout ไม่พัง
- [ ] 👤 กดชำระเงิน → ไปหน้าใบเสร็จ **แล้วกด back กลับมา บิลต้องว่าง** (กันออกบิลซ้ำ)

## 5. ใบเสร็จ · PromptPay · แชร์ (FR-4)

- [ ] 👤 ใบเสร็จแสดงครบ: โลโก้ ชื่อร้าน สาขา เบอร์ เลขบิล วันที่ รายการ ยอด รับเงิน ทอน
- [ ] 👤 **วันที่ต้องเป็น ค.ศ. (2026) ไม่ใช่ พ.ศ. (2569)**
- [ ] 👤 เลขบิลรูปแบบ `DDMMYYYY-NNNNNNNN` และ **ออกบิลถัดไปเลขต้องเดินต่อ ไม่ซ้ำ**
- [ ] 👤 **🔥 สแกน QR ด้วยแอปธนาคารจริง → ต้องขึ้นชื่อบัญชีถูกและยอดเงินตรงกับบิล**
      อันนี้สำคัญที่สุดในทั้งแอป — เงินเข้าผิดบัญชีคือจบ
- [ ] 👤 กด "บันทึกรูป" → ได้ไฟล์ PNG · **เปิดรูปดู: QR อยู่ในรูป สีไม่เพี้ยน ไม่มีปุ่มติดมาในรูป**
- [ ] 👤 **🔥 กด "แชร์บิล" บนมือถือจริง → ส่งเข้า LINE → ปลายทางเห็นรูปพร้อม QR**
- [ ] 👤 กด "คัดลอกลิงก์" → เอาไปเปิดในแท็บใหม่ได้
- [ ] 👤 กด "ดูบิลออนไลน์" → เปิดหน้าบิลของลูกค้า
- [ ] 👤 **ร้านที่ยังไม่ตั้ง PromptPay** → ไม่มี QR จ่ายเงิน แต่มี QR เปิดบิลออนไลน์แทน
      และมีลิงก์ชวนไปตั้งค่า

### หน้าบิล public `/r/<token>`
- [ ] 👤 **เปิดในหน้าต่างไม่ระบุตัวตน (ไม่ล็อกอิน) → ต้องเปิดได้**
- [ ] 👤 หน้านี้ **ไม่มีแท็บล่าง ไม่มีปุ่มเข้าแอป** — เป็นหน้าอ่านอย่างเดียว
- [ ] 🤖 แก้ token ใน URL มั่วๆ → 404 พร้อมข้อความสุภาพ ไม่ใช่ error ดิบ
- [ ] 🤖 ไม่มีข้อมูลร้านอื่นหรือเลข PromptPay รั่วในหน้านี้

## 6. ต้นทุน (FR-5)

- [ ] 👤 บันทึกการซื้อพร้อมรายการย่อย 3 รายการ → **ยอดรวมคิดสดขณะพิมพ์**
- [ ] 👤 กด "เพิ่มรายการ" หลายๆ ครั้ง → เพิ่มได้ไม่จำกัด
- [ ] 👤 ลบรายการย่อยกลางๆ ออก → **ยอดรวมอัปเดตทันที**
- [ ] 👤 ติ๊ก "กรอกยอดรวมเอง" → ใส่ยอดเอง → ยอดที่บันทึกเป็นยอดที่กรอก ไม่ใช่ผลรวม
- [ ] 👤 บันทึกใบเปล่า (ไม่มีรายการ ไม่มียอด) → ขึ้น "ต้องมีอย่างน้อย 1 รายการ หรือกรอกยอดรวมเอง"
- [ ] 👤 แนบสลิป (รูปและ PDF) → บันทึกได้ → เปิดหน้าแก้ไขแล้วกด "ดูสลิป" เปิดไฟล์ได้
- [ ] 👤 แนบไฟล์ใหญ่เกิน 10 MB → ขึ้นข้อความบอกขนาด
- [ ] 🤖 แก้บันทึกเดิม → รายการเก่าถูกแทนที่ทั้งชุด ยอดคิดใหม่ถูก
- [ ] 👤 ลบบันทึก → ต้องยืนยันก่อน → **ยอดต้นทุนเดือนนี้ลดลงทันที**
- [ ] 👤 บันทึกการซื้อ **ย้อนหลังไปเดือนก่อน** → ไปโผล่ในกำไรของเดือนนั้น ไม่ใช่เดือนนี้
- [ ] 👤 การ์ดต้นทุนโชว์วันที่ ชื่อร้าน จำนวนรายการ ยอด — เรียงล่าสุดก่อน

## 7. สรุป · รายงาน (FR-6)

- [ ] 👤 ออกบิล 2–3 ใบวันนี้ → **ยอดขายวันนี้ตรงกับผลบวกด้วยมือ**
- [ ] 👤 **กำไรเดือนนี้ = ยอดขายเดือนนี้ − ต้นทุนเดือนนี้** (คิดเองแล้วเทียบ)
- [ ] 👤 กราฟ 7 วัน — แท่งวันนี้เป็นสีเข้มกว่าเพื่อน วันที่ไม่มีบิลมีแท่งเตี้ยๆ ไม่หายไป
- [ ] 👤 หน้ากำไรรายเดือน → เลือกเดือนก่อน → ตัวเลขเปลี่ยน **และ URL เปลี่ยนด้วย**
- [ ] 👤 กด back ของเบราว์เซอร์ → กลับไปเดือนก่อนหน้าที่เลือก
- [ ] 👤 % เทียบเดือนก่อน — ขึ้นลูกศรขึ้น/ลงถูกทาง · เดือนก่อนไม่มีข้อมูล → บอกว่าไม่มีข้อมูล
- [ ] 👤 รายงานยอดขาย: ปุ่ม "วันนี้" / "เดือนนี้" / เลือกช่วงเอง → ตัวเลขเปลี่ยนถูก
- [ ] 👤 เลือกช่วงที่ไม่มีบิลเลย → ขึ้น ฿0.00 ไม่พัง
- [ ] 👤 **VAT ปิด → ไม่มีบรรทัด "ภาษีรวม" ในรายงาน · VAT เปิด → มี**
- [ ] 👤 รายการบิลทั้งหมด: กรองตามวันที่ / ค้นหาเลขบิล → ได้ผลถูก
- [ ] 👤 **แตะบิลในรายการ → เปิดใบเสร็จเดิมได้** และ QR ยังถูกต้อง

## 8. เงินและตัวเลข — ตรวจแบบจับผิด

- [ ] 👤 **ทุกตัวเลขเงินมี 2 ตำแหน่งทศนิยมเสมอ** (฿45.00 ไม่ใช่ ฿45)
- [ ] 👤 **ตัวเลขไม่เต้นตอนเปลี่ยนค่า** — กด +/− เร็วๆ ดูว่าคอลัมน์ยอดขยับซ้ายขวาไหม
- [ ] 👤 ยอดหลักพัน/หมื่นมีคอมมา (฿12,050.00)
- [ ] 👤 **บิลที่มีสตางค์เยอะๆ**: สินค้า 33.33 × 3 = 99.99 ไม่ใช่ 100.00 หรือ 99.98
- [ ] 👤 **VAT เปิด**: ยอดภาษีคิดที่ระดับบิลครั้งเดียว — ลองบิลหลายรายการแล้วบวกมือเทียบ
- [ ] 👤 เงินทอน = รับเงิน − ยอดสุทธิ เป๊ะ

## 9. ความปลอดภัย · ข้อมูลข้ามร้าน

> 🤖 ทดสอบด้วยการยิง API ตรงไปแล้วทุกข้อ — ที่ต้องดูคือ **ฝั่ง UI ไม่หลุด**

- [ ] 👤 ล็อกอินร้าน A แล้วเอา URL ของร้าน B มาเปิด (เช่น `/products/<id ของร้าน B>`) → **404**
- [ ] 👤 ร้าน A ไม่เห็นสินค้า/บิล/ต้นทุน/ยอดของร้าน B **ที่หน้าไหนเลย**
- [ ] 🤖 ลบสินค้าจริงผ่าน API → ทำไม่ได้ (มีแต่ archive)
- [ ] 🤖 แก้/ลบการซื้อของร้านอื่น → ถูกปฏิเสธ
- [ ] 👤 ลิงก์บิล public ไม่มี id ร้าน ไม่มีเลข PromptPay อยู่ในหน้า (กด view-source ดู)

## จุดที่ถ้าจะพัง น่าจะพังตรงนี้

เรียงตามความเสียหายถ้าพลาด — ถ้ามีเวลาจำกัด เทส 5 ข้อนี้ก่อน

1. **สแกน QR ด้วยแอปธนาคารจริง แล้วยอดกับบัญชีถูก** — ผิดแปลว่าเงินเข้าผิดคน
2. **แชร์บิลเข้า LINE แล้วรูปมี QR และสีไม่เพี้ยน** — เป็นฟีเจอร์ที่ลูกค้าซื้อ
3. **รีเฟรชกลางบิลแล้วบิลไม่หาย** — เกิดจริงบ่อยตอนขายหน้าร้าน
4. **เลขบิลไม่ซ้ำเมื่อออกพร้อมกันสองเครื่อง** — ลองเปิดสองเบราว์เซอร์กดชำระพร้อมกัน
5. **ร้าน A ไม่เห็นอะไรของร้าน B เลย** — รั่วครั้งเดียวคือจบ
